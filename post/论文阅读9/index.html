Test-Time Adaptation for LLM Agents via Environment Interaction

研究动机

LLM 智能体虽然能够完成网页导航、工具使用和函数调用等任务，但部署到新环境后常常出现明显的泛化失败。

  1. 语法不匹配：模型不熟悉当前环境的观察格式、按钮名称、字段名称或函数调用格式。
  2. 语义不匹配：模型不了解当前环境的状态转移规律，无法预测一个动作执行后会产生什么结果。

本文旨在研究如何让基于大语言模型的智能体在部署到从未见过的网站、API 或工具环境后，利用测试阶段与环境交互得到的信息快速适应，而不依赖人工标注数据或昂贵的重新训练。针对上述两类问题，论文分别提出：

  • 语法对齐（Syntactic Alignment，SA）：在线更新一个轻量级适应向量，使模型输出分布快速贴合当前环境。
  • 动态语义落地（Dynamics Grounding，DG）：正式执行任务前先自动探索环境，将状态转移总结成自然语言规则，作为上下文内世界模型供智能体使用。

方法

语法对齐（SA）

SA 引入一个轻量级适应向量：

\[ \delta \in \mathbb{R}^{d} \]

其中 \(d\) 是语言模型隐藏层维度。

设模型最后一层隐藏表示为：

\[ H \in \mathbb{R}^{n \times d} \]

适应向量作为加性偏置加入隐藏表示，得到调整后的输出：

\[ \text{logits}'=(H+\delta)W_{\mathrm{LM}}^{T} \]

模型主体参数 \(\theta\) 保持冻结，只更新适应向量 \(\delta\)。系统使用当前输入上下文进行next token prediction，并执行一步梯度下降：

\[ \delta_{\mathrm{new}} \leftarrow \delta_{\mathrm{old}} -\eta\nabla_{\delta} \mathcal{L}_{\mathrm{CE}} \left( f_{\theta,\delta}(I_{1:n-1}), I_{2:n} \right) \]

示例：

假设网页观察中出现：

1
2

[145] <button>Go
dest_field

未经适应时，模型可能受预训练先验影响，更倾向生成：

1

click("Search")

SA 在当前上下文上计算语言建模损失。由于 Go 和 dest_field 出现在上下文中，梯度更新会提高相关词元在模型输出中的倾向，使后续生成更可能变为：

1

click("Go")

动态语义落地（Dynamics Grounding，DG）

DG 解决语义不匹配问题。它在正式接收用户任务前，对环境进行一次自动探索，学习“执行某个动作会发生什么”，并将这些状态转移规律总结为自然语言规则。

这些规则在正式任务中被加入智能体上下文，形成一个临时的、上下文内的"世界"模型。

探索成本只需支付一次，之后可以分摊到该环境中的所有任务。

系统首先向 LLM 提供环境的高层描述，例如：

  • 网站用途；
  • API 文档；
  • 可用工具及功能说明。

LLM 据此生成多样化的探索用户画像或目标。例如：

作为第一次使用该网站的用户，我想看看在没有选择日期时搜索航班会发生什么。

针对每个用户画像，探索智能体与环境交互，并尽量尝试新的动作。

每执行一个动作，系统记录：

\[ (\text{旧观察},\text{动作},\text{新观察}) \]

然后由 LLM 将这一状态转移总结为人类可读的规则，例如：

在主页执行 click("Go") 会弹出日期选择窗口。

新生成的规则会立即添加到探索智能体上下文中，以提醒它不要重复已经探索过的转移，促进发现更多新规律。

全部探索完成后，系统得到原始规则集合：

\[ E=\{e_i\}_{i=1}^{M} \]

然后使用推理模型过滤，得到清理后的规则集合：

\[ E_{\text{clean}} \]

正式执行任务时，将环境动态规则加入原始输入：

\[ I'=[I;E_{\text{clean}}] \]

LLM 利用上下文学习能力，根据这些规则预测动作后果并制定更加可靠的多步计划。

三、实验

论文在三个现实智能体基准上进行评估：

WebArena 网页导航
BFCLv3 函数调用
Tau-Bench 对话式函数调用

实验使用的主要模型包括：

  • GPT-4.1；
  • GPT-4o mini；
  • Qwen2.5-14B-Instruct。

与 WMA（World-Model-Augmented Agent）进行比较。

WMA 需要：

  1. 收集探索示范；
  2. 训练一个 Llama-3.1-8B-Instruct 世界模型；
  3. 在推理过程中预测动作对应的下一状态。 文章提出的两种方法并不互补，论文测试了直接将DG与SA二者结合的方法，但结果并不稳定：
  • WebArena：DG 为 20.0%，Hybrid 为 21.0%；
  • BFCLv3：DG 为 22.0%，Hybrid 下降到 21.0%。

Prototype-Based Test-Time Adaptation of Vision-Language Models 论文总结

研究动机

本文针对无需反向传播的VLM（CLIP）TTA，这类方法此前大多基于缓存，存在两个问题：

  1. 推理效率下降 ：缓存的规模通常与类别数有关。类别越多，缓存越大，检索和维护缓存的成本越高。

  2. 性能依赖缓存状态 ：在测试流开始阶段，缓存为空或样本很少，方法很难发挥作用。同时，缓存方法通常只保留低熵或高置信度样本，可能丢弃有用样本，也可能保留错误样本，从而造成误差累积。

本文方法希望通过为每类维护原型，来解决上述问题

方法

CLIP 包含视觉编码器和文本编码器：

  • 视觉编码器：\(E_V\)
  • 文本编码器：\(E_T\)

给定测试图像 \(x\)，视觉编码器得到图像特征：

\[ F_g = E_V(x) \in \mathbb{R}^d \]

通过文本编码器得到每个类别的文本特征：

\[ \{F_t^c\}_{c=1}^{C}, \quad F_t^c \in \mathbb{R}^d \]

CLIP 根据图像特征和文本特征的余弦相似度计算类别概率：

\[ p_{\text{CLIP}}(y_c|x) = \frac{\exp(\cos(F_g, F_t^c)/\tau)}{ \sum_{c=1}^{C}\exp(\cos(F_g, F_t^c)/\tau)} \]

PTA 首先零初始化一组类别特定的知识原型：

\[ P_t \in \mathbb{R}^{C \times d} \]

其中第 \(c\) 类的知识原型为：

\[ P_t^c \in \mathbb{R}^d \]

给定测试样本 \(x\)，PTA 首先使用原始 CLIP 得到类别置信度：

\[ s = p_{\text{CLIP}}(y|x) \]

其中 \(s_j\) 表示当前样本对类别 \(j\) 的贡献程度。

如果一个样本被 CLIP 判断为更像某个类别，那么它对该类别原型的更新贡献就应该更大。

直接使用原始置信度 \(s_j\) 作为更新权重可能导致早期高置信度样本过度主导原型。
因此，PTA 对置信度进行一个变换：

\[ \beta_j = 1 - e^{-s_j/h} \]

PTA 使用EMA更新类别知识原型：

\[ P_t^j \leftarrow (1-\beta_j)P_t^j + \beta_j F_g \]

仅使用视觉知识原型 \(P_t\) 可能会导致原型逐渐偏离 CLIP 原本的图文联合语义空间。
为了保持与文本语义空间的对齐，PTA 引入文本锚定原型 \(P_a\)。

文本锚定原型初始化自 CLIP 的文本嵌入：

\[ P_a^{(0)} = F_t \]

随后，通过插值方式将测试域视觉知识与文本语义锚点结合：

\[ P_a^{(t)} = (1-w)P_t^{(t)} + wP_a^{(t-1)} \]

2.5 基于原型的预测

使用文本锚定原型 \(P_a\) 计算基于原型的预测概率：

\[ p_{\text{Prototype}}(y_c|x) = \frac{\exp(\cos(F_g, P_a^c)/\tau)}{ \sum_{c=1}^{C}\exp(\cos(F_g, P_a^c)/\tau) } \]

最后，PTA 将原始 CLIP 的零样本预测与基于原型的预测相加：

\[ p_{\text{PTA}}(y|x)= p_{\text{CLIP}}(y|x)+ p_{\text{Prototype}}(y|x) \]

实验

论文在图像识别数据集（CLIP）和点云分类数据集（ULIP）上评估PTA。BoostAdapter、TDA、SCA 和 ADAPT均为缓存式方法。
