UNOPose 与 COG 论文总结

主题：基于单张、无位姿 RGB-D 参考图像的新物体 6DoF 位姿估计
论文：UNOPose（CVPR 2025）与 COG（CVPR 2026）

1. 概要

两篇论文研究的是同一个设定：测试时只给一张查询（query）RGB-D 图像和一张同一未知物体的参考（reference）RGB-D 图像；参考图不带位姿标注，也没有目标物体的 CAD 模型，需要估计两次观测之间的相对 6DoF 位姿。

  • UNOPose 的核心贡献是“先把问题变容易”：通过全局参考系（GRF）把任意 SE(3) 输入规范化，再以局部参考系（LRF）补充细粒度几何，并显式预测重叠区域，在监督训练下完成由粗到细的配准。
  • COG 的核心贡献是“重新定义对应关系”：沿用 UNOPose 的单参考、RGB-D、粗到细骨架，但把离散的一对一匹配改成置信度感知的最优传输（OT）。点置信度直接充当 OT 的边缘分布，DINOv2 语义特征充当先验，使对应、置信度和位姿求解形成可微闭环，从而不使用真实位姿或真实重叠标签也能训练。
  • 因此，两者更像一条连续的技术路线，而不是互不相关的竞争方案：UNOPose 主要解决任意初始位姿与低重叠；COG 主要解决离散匹配不可微、匹配质量不均衡以及训练依赖姿态标签。

2. 共同任务与研究背景

2.1 为什么要做“新物体”位姿估计

6DoF 物体位姿包含三维旋转和三维平移，是机器人抓取、增强现实和三维场景理解的基础。传统方法通常属于以下两类：

  1. 实例级方法：训练和测试物体相同，常依赖每个物体的 CAD 模型与位姿标注。
  2. 类别级方法：可处理预定义类别中的新实例，但类别范围固定，仍不是真正的开放世界泛化。

新物体位姿估计希望模型在训练时没见过目标物体，测试时只进行轻量的物体“接入”（onboarding）。然而，很多现有方法仍要求 CAD 模型、提前渲染的模板库、多张带位姿参考图，或通过 SfM 重建目标物体。这些准备过程限制了实际扩展能力。

2.2 单张无位姿参考为什么困难

只使用一张无位姿 RGB-D 参考图虽然接入成本最低，却带来三个直接问题：

  • 变换范围大：参考位姿不再是已知锚点，query 与 reference 的相对变换可能覆盖整个 SE(3)。
  • 观测是 partial-to-partial：两张深度图都只看到物体的一部分；大视角差、遮挡和深度噪声会使真实重叠区域很小。
  • 对应易歧义：对称结构、重复部件、纹理缺失及外点会让几何或语义匹配集中到少数“强点”，进而产生错误姿态。

任务可写为：给定 query 点云 $P$ 与 reference 点云 $Q$，寻找旋转 $R\in SO(3)$ 和平移 $t\in\mathbb{R}^3$，使二者的有效重叠部分满足

$$ Q_{\mathrm{val}} \approx P_{\mathrm{val}}R + \mathbf{1}t^\top. $$

由于没有统一的物体规范坐标系，论文估计的是两张图之间定义良好的相对位姿，而不是物体在某个先验 CAD 坐标系中的绝对位姿。

3. UNOPose

3.1 论文信息

  • 标题：UNOPose: Unseen Object Pose Estimation with an Unposed RGB-D Reference Image
  • 作者：Xingyu Liu、Gu Wang、Ruida Zhang、Chenyangguang Zhang、Federico Tombari、Xiangyang Ji
  • 会议：CVPR 2025
  • 关键词：单张无位姿参考、SE(3) 规范化、GRF/LRF、重叠预测、粗到细配准

3.2 研究动机

此前的新物体位姿方法往往用 CAD 模型或多张带位姿图像把搜索范围限制在参考附近。UNOPose 希望把物体接入简化为“拍一张 RGB-D 照片”，但这样会失去已知参考坐标系，并使相对姿态的范围扩大到整个 SE(3)。作者据此提出两个关键问题：

  1. 如何让网络在任意旋转、平移和物体尺度下仍获得一致的表示？
  2. 如何在两张仅部分重叠的点云之间找到可靠、足够稠密的对应？

3.3 方法

UNOPose 包含查询物体分割和相对位姿估计两个部分。

3.3.1 UNOSeg：用单张参考图定位查询物体

  1. 使用 SAM 或 FastSAM 在 query 图像中生成候选分割掩码。
  2. 使用 DINOv2 提取 query 候选区域和 reference 物体的视觉描述子。
  3. 通过余弦相似度选择与 reference 最相似的 query 候选掩码。

该设计不需要目标物体 CAD 模型；reference 本身同时承担目标身份提示和相对位姿坐标来源。

3.3.2 GRF：构造 SE(3) 不变的全局参考系

UNOPose 分别从 query/reference 的观测点云自身构造 Global Reference Frame（GRF）。对点云中的点 $x$，规范化形式可概括为

$$ x_G=R_G^\top(x-c)/s, $$

其中：

  • $c$ 是点云中心，使表示对平移不敏感；
  • $s=\max_x\|x-c\|_2$，把物体半径归一化为 1；
  • $R_G$ 由点云的中心法向、协方差 SVD 和主投影方向确定，给出可重复的规范方向。

GRF 将原本覆盖整个 SE(3) 的输入转换到近似一致的表示空间，主要帮助获得可靠的粗位姿初始化。它本质上是一个由当前可见点云决定的 7DoF 规范化（旋转、平移和尺度）。

3.3.3 粗阶段：稀疏特征匹配与姿态假设选择

  1. 对 GRF 中的 query/reference 点云做稀疏采样。
  2. 几何编码器提取点云特征，DINOv2 提供 RGB 颜色/语义特征；二者拼接后进入 3 层 Geometric Transformer。
  3. 加入可学习的 background token，吸收无对应的非重叠点。
  4. 网络预测每个点位于重叠区域的概率，并用 query/reference 两侧的 overlap confidence 重标定相关矩阵。
  5. 按对应概率采样三点组，生成多个刚体位姿假设；再按对齐后的点云距离评分，选择最佳粗位姿。

3.3.4 细阶段：LRF、稠密匹配与加权 SVD

先用粗位姿对齐 query，再对更稠密的点集进行细化：

  • **位置编码（FPE 中的 positional encoding）**提供全局位置上下文；
  • **局部参考系（LRF）**在每个点的邻域内以类似 GRF 的方式构造局部规范坐标，提取对姿态不敏感的细粒度结构；
  • 细阶段再次进行 overlap-aware 稠密相关性计算；
  • 最后利用高置信对应，通过 weighted SVD 求得最终相对旋转与平移。

GRF 与 LRF 的分工很清楚：前者解决大范围初始位姿变化，后者在粗对齐后辨别局部几何细节。

3.4 实验

3.4.1 设置

  • 训练数据：MegaPose 合成训练集，约 200 万张 RGB-D 图像、约 5 万个 GSO/ShapeNet 物体。
  • 训练：3 个 epoch，batch size 32，4 张 RTX 3090；DINOv2 ViT-B 提取颜色特征。
  • 测试集：LM-O、TUD-L、YCB-V。
  • reference 选择：默认 query 与 reference 最大旋转差为 $50^\circ$，reference 遮挡率低于 30%，且参考物体样本来自测试图像之外。
  • 分割指标：跨 IoU 0.50–0.95 的 mAP。
  • 位姿指标：BOP AR，即 VSD、MSSD、MSPD 三种 Average Recall 的均值；时间按每张图统计。

3.4.3 消融与鲁棒性

  • GRF/LRF/FPE（YCB-V）：不使用三者时 AR 为 63.9；仅 GRF 为 67.5，仅 LRF 为 65.4，GRF+LRF 为 67.9；加入 fine pose estimation 后，完整模型达到 81.5。说明 GRF 对粗阶段贡献更明显，LRF 主要改善细阶段。
  • 重叠预测：soft correspondence 方案为 77.2，使用 overlap predictor 后为 83.1，提升 5.9。
  • 分割上限：换成 GT segmentation 后 AR 从 83.1 升至 86.0，说明分割误差会向位姿阶段传播。
  • 参考质量：使用位姿相同的渲染 reference 可达 85.5，但这重新引入了 CAD 模型需求。
  • 每类仅一个 reference：在 TUD-L 上平均 AR 为 60.7，说明极少量参考仍可工作，但明显低于逐查询选择较合适 reference 的设置。
  • 视角差：当旋转差超过 $50^\circ$ 后性能明显下降；$80^\circ$–$90^\circ$ 组的平均重叠率为 45.4%，AR 为 54.8。

3.5 优势与局限

优势：接入成本低；GRF/LRF 对任意姿态提供结构化归一化；融合 RGB 语义与深度几何；重叠预测适合 partial-to-partial 注册；速度显著快于部分传统配准基线。

局限：方法仍依赖 query/reference 之间存在足够稠密且可靠的对应。极大视角差、极低重叠、严重深度噪声或极端双视图几何会直接削弱性能。作者建议未来从单张图重建不可见区域，再联合估计位姿。

4. COG

4.1 论文信息

  • 标题：COG: Confidence-aware Optimal Geometric Correspondence for Unsupervised Single-reference Novel Object Pose Estimation
  • 作者：Yuchen Che、Jingtu Wu、Hao Zheng、Asako Kanezaki
  • 会议：CVPR 2026
  • 关键词：无监督学习、置信度感知最优传输、soft correspondence、语义先验、可微 SVD

4.2 研究动机

UNOPose 已证明“单张无位姿 RGB-D reference”可行，但其对应构造及同类方法常使用 argmax 等离散一对一分配，并依赖 GT pose/GT correspondence 或 GT overlap 监督。COG 认为这有三项根本问题：

  1. 离散分配不可微，对应模块与位姿目标难以端到端联合优化；
  2. 匹配容易坍缩到少量显著关键点，很多有效点得不到利用；
  3. 低重叠和外点下不平衡，后处理式置信度无法从对应生成阶段就控制运输质量。

COG 的目标是在与 UNOPose 相同的输入设定下，不使用 CAD、真实位姿或真实重叠分数，联合学习点有效性、跨视图对应和相对位姿。

4.3 方法

4.3.1 延续 UNOPose 的粗到细骨架

COG 使用 UnoSeg 获得物体掩码，将深度反投影为点云，并提取 DINOv2 特征。其主干与直接基线 UNOPose 保持一致：

  • 粗阶段以最远点采样得到 256 个稀疏点，使用 SE(3)-invariant 几何编码与 Geometric Transformer；
  • 细阶段使用 1024 个点和位置编码进行稀疏到稠密细化；
  • query/reference 两个方向对称地估计 soft correspondence；
  • 推理时默认执行一次 iterative refinement。

真正的变化集中在对应表示、置信度的作用方式和训练目标。

4.3.2 置信度作为 OT 的边缘分布

网络用一个轻量 MLP+Sigmoid 为两侧每个点预测置信度 $c_p,c_q\in[0,1]^n$，并按均值归一化为

$$ w_p=c_p/\bar c_p,\qquad w_q=c_q/\bar c_q. $$

$w_p,w_q$ 不是在匹配后乘上的分数，而是直接成为最优传输的行、列目标边缘分布。直观上：

  • 高置信、可能位于重叠区域的点获得更多运输质量；
  • 非重叠点和外点的运输质量被压低；
  • 全局边缘约束避免所有点都挤向少量显著关键点；
  • many-to-many 的 soft transport 允许稀疏高置信区域对应另一侧更密集的区域。

4.3.3 几何 affinity 与语义先验

几何特征 $G_p,G_q$ 的余弦相似度构成基础 affinity。DINOv2 特征先经 STEGO 风格的语义去噪头得到 $S_p,S_q$，再以非线性调制形式注入 OT kernel：

$$ K_{ij}=\exp\!\left(\frac{\langle G_{p,i},G_{q,j}\rangle_{\cos}}{\tau}\right) \left(1+\langle S_{p,i},S_{q,j}\rangle_{\cos}\right)^{\lambda/\tau}. $$

其中语义先验权重 $\lambda=3$。论文采用 log-domain Sinkhorn 求解运输矩阵 $\Pi$，默认 2 次迭代。语义先验不是硬性部件标签，而是软约束：它抑制跨语义部件的错误匹配，同时避免完全覆盖几何证据。

4.3.4 Soft correspondence 与可微位姿求解

对 $\Pi$ 分别做行归一化，得到双向对应矩阵 $M_{pq}$ 和 $M_{qp}$。例如 $M_{pq}Q$ 表示 $P$ 中每个点在 $Q$ 上的凸组合对应，而不是单个 argmax 点。随后把两侧原始点与双向软对应拼接，以置信度为权重，通过 Umeyama/weighted SVD 得到相对位姿。

这条路径从 affinity、Sinkhorn、soft correspondence 到 SVD 都可微，使姿态误差能够反向影响对应与置信度学习。

4.3.5 无监督损失与伪置信度

粗、细阶段都使用以下自监督信号：

  • Cycle consistency loss：点从一侧软投影到另一侧再投影回来，应接近原位置；
  • Confidence-weighted Chamfer pose loss：预测位姿变换后的高置信点应贴近另一侧点云；
  • Semantic consistency loss：运输质量不应分配给语义不一致的点；
  • Confidence BCE loss：监督点置信度分支；
  • STEGO-style feature consistency：去噪并对齐跨视图 DINO 语义特征。

由于没有真实置信度标签，COG 以 cycle、Chamfer 和 semantic 三种高斯 RBF 一致性生成软伪标签。论文公式用三者乘积表示；发布实现进一步使用 0.35、0.35、0.30 作为乘积指数，并对伪标签 stop-gradient，再用 BCE 训练置信度头。归一化置信度还避免训练初期所有置信度接近零时出现退化梯度。

监督版 COG 仅把无监督的 Chamfer pose 目标替换为利用 GT pose 的点级变换误差，用于展示该对应框架在有监督条件下的上限。

4.4 实验

4.4.1 设置

  • 训练数据与 UNOPose 一致：GSO + ShapeNet，共约 200 万张 RGB-D 图像、超过 5 万个物体。
  • 训练：Adam，初始学习率 $10^{-4}$，3 个 epoch，batch size 32。
  • 测试：LM-O（200 张、8 个物体）、TUD-L（600 张、3 个物体）、YCB-V（900 张、21 个物体）。
  • 为公平对比，COG 对各方法使用与 UNOPose 相同的 query-reference 对和分割掩码。
  • 位姿指标：论文称为 BOP mAP，由 VSD、MSSD、MSPD 聚合；另报告重叠区域 IoU 与包含分割、DINO 特征和位姿估计的总推理时间。

主要观察：

  • 无监督 COG 比监督 UNOPose 平均只低 2.1 个百分点，且在几何结构较复杂的 TUD-L 上高 2.8 个百分点。
  • 在遮挡/杂乱更严重的 LM-O 和 YCB-V 上，无监督 COG 分别落后 UNOPose 2.0 和 7.2，说明无监督几何目标在复杂场景仍有明显改进空间。
  • 监督 COG 的平均结果为 73.8，高于 UNOPose 2.9；优势主要来自 TUD-L（+9.0）。但它在 YCB-V 为 80.5，低于 UNOPose 的 83.1，因此不能概括为在每个数据集上都更强。
  • 相比统一主干上的 Robust OT 和 Dustbin OT，无监督 COG 在三个数据集上均更好，支持“置信度应进入 OT 边缘分布，而非只做后处理”的主张。

  • 不使用语义先验、2 次 Sinkhorn 时 mAP 为 73.2；加入语义先验后为 75.9，同时对应熵显著降低，匹配更集中。

4.5 优势与局限

优势：无需真实姿态、真实对应或真实重叠分数；soft OT 保持端到端可微；置信度从对应生成阶段就抑制非重叠点；几何与语义互补；在少量训练数据下仍有较强泛化。

局限：

  1. COG 依赖前置分割；掩码把其他物体或背景包含进来时，错误几何会直接传播到位姿阶段。
  2. 无监督位姿主要由置信度加权 Chamfer 间接优化，它倾向于降低高置信点距离，并不显式保证全局位姿正确。稀疏、细小但有判别力的部件可能被忽略，例如杯柄点数少时，模型可能只对齐杯身。
  3. DINO 语义先验只是软约束，不能完全消除上述局部最优。作者建议引入混合监督或语义部件级结构硬约束。

5. 两种方法的相同点

  1. 任务完全一致：都估计 query 与单张无位姿 RGB-D reference 之间的新物体相对 6DoF 位姿，不要求测试物体 CAD。
  2. 输入与前处理相近：都先分割物体，再把深度反投影成 partial point cloud，同时利用 RGB 和深度。
  3. 使用视觉基础模型：都以 DINOv2 提供跨视图颜色/语义特征。
  4. 粗到细框架：都先稀疏点求粗位姿，再以稠密点和位置编码细化。
  5. 融合几何与语义：两者都不把纯 RGB 或纯点云作为唯一证据。
  6. 显式处理低重叠：UNOPose 预测 overlap probability；COG 预测 point confidence 并将其作为 OT marginals。
  7. 同一评测生态：都用 MegaPose/GSO/ShapeNet 训练数据，并在 LM-O、TUD-L、YCB-V 上按 BOP 指标评估。
  8. 共同瓶颈：前置分割错误、极低重叠、大视角差、对称或稀疏部件都会降低最终位姿精度。

7. 如何理解 UNOPose → COG 的方法演进

可以把两篇论文放在同一条处理链上理解：

$$ \text{RGB-D 分割与反投影} \rightarrow \text{SE(3) 不变表示} \rightarrow \text{跨视图对应} \rightarrow \text{刚体位姿求解}. $$
  • UNOPose 的重点落在第二和第三环节：利用 GRF/LRF 提高表示的一致性，再显式预测重叠区域以筛选对应。
  • COG 保留上述前端与粗到细结构，把第三和第四环节改造成可微的概率运输与 SVD，并用闭环一致性反过来训练点置信度。

因此，COG 并没有否定 UNOPose 的规范化思想，而是把 UNOPose 中“预测重叠分数、选择离散对应、再求姿态”的流程，升级为“学习置信边缘、求全局平衡 soft correspondence、可微求姿态、用几何/语义一致性自监督”的闭环。
